### Luiz

Trabalho com tecnologia em escola e boa parte do que está aqui nasceu de problemas do dia a dia: tablets que os alunos desconfiguravam, laboratório que precisava voltar ao estado limpo a cada aula, contas de alunos que precisavam ser criadas e corrigidas uma a uma numa plataforma educacional.

Escrevo principalmente **Python** (automação, Selenium, scripts de apoio), **Kotlin** (Android, Device Owner) e **PowerShell** (configuração de máquinas Windows). Também desenvolvo aplicações web com **React** e **Firebase**.

#### Projetos

| Projeto | O que é | Stack |

| [Gestao-de-Tablets](https://github.com/LUIZBAKER77/Gestao-de-Tablets) | App Android que trava tablets escolares em modo aluno usando Device Owner, com painel do administrador e configurador para Windows | Kotlin, DevicePolicyManager, GitHub Actions, Python |
